O que significa 45,8dB?

É um resultado de referência PNG-8 existente de 256 cores usado para detectar regressões de algoritmos. Não é uma média, uma garantia universal ou uma prova suficiente de que uma ferramenta vence sempre. Capturas de tela, fotos, ilustrações planas e sombras alfa precisam de grupos de teste separados.

A escolha do formato é mais importante do que uma “qualidade 80” universal

Prefira WebP, JPG ou AVIF para fotos; PNG-8 para gráficos alfa de cores limitadas; GIF para alcance máximo de animação; WebP para animação web moderna; e APNG para animação alfa curta e em cores reais.

Perguntas frequentes

Essas respostas visíveis correspondem ao comportamento atual do produto e aos dados estruturados.

Um PSNR mais alto é sempre melhor?

Não. O PSNR é útil para regressão de pixels, enquanto a textura percebida, os contornos, o texto e as bordas transparentes ainda exigem inspeção visual.

45,8 dB é uma média em todas as imagens?

Não. É uma amostra de referência atual de 256 cores, não um resultado universal.

Os testes de codec devem usar tamanho de arquivo igual?

Comparações de igual tamanho e de igual qualidade são úteis, mas as suas conclusões não devem ser confusas.
