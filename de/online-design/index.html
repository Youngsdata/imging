Wie funktionieren mehrseitige Projekte?

One .imging v3 project stores up to 24 independent pages. Each page owns its true canvas size, background, layers and global filters; switching pages never rescales or merges them.

Was ist anders als bei dauerhaft in das Bild gerechneten Filtern?

ImgIng uses a non-destructive structure similar to professional adjustment layers. Original asset bytes are never re-encoded: image adjustments run before scale and rotation, while canvas adjustments run after every layer and the background are composited. Editable text stores its own content and style. The open .imging v3 manifest keeps all pages for undo, redo, reopening and hand-off, while v1 and v2 projects remain supported.

Welche Sprachen und Schriften unterstützen Textebenen?

Der integrierte Satz deckt Chinesisch, Englisch, Japanisch, Koreanisch, Deutsch, Spanisch, Portugiesisch und Französisch ab. Alimama ShuHeiTi dient für Chinesisch, Noto Sans für lateinische Sprachen und eigene Noto-CJK-Dateien für Japanisch und Koreanisch. Schriften laden erst bei der ersten Auswahl; Vorschau, Projektvorschau und Export warten auf exakt diese Schrift.

Wie wird mit großen und transparenten Bildern umgegangen?

The interactive preview uses an adaptive resolution, while export preserves each page’s requested dimensions. High-resolution effects run in overlapping bands to control peak memory and avoid seams. Every adjustment preserves source alpha, so cutouts, shadows and translucent artwork remain valid.

Each page remains limited to 8192 px per side, 48 megapixels and 24 image or text layers; one project supports up to 24 pages. Skin-aware beauty is a local colour-and-detail algorithm, not face reshaping or identity recognition.

Häufig gestellte Fragen

Diese sichtbaren Antworten entsprechen dem aktuellen Produktverhalten und strukturierten Daten.

Lädt das Online-Design mein Projekt hoch?

No. Image decoding, font loading, filter preview, full-size processing, page management and final compositing run in the current browser. Font files are downloaded assets; project content is not uploaded.

Will changing one font affect every text layer?

No. The selected font ID is stored on that text layer only. On-demand loading then repaints the current layer without rewriting the other text layers.

Kann eine andere Person alle Seiten weiterbearbeiten?

Yes. The .imging v3 manifest stores every page, editable text, image adjustments, original assets and a rendered preview, while older v1 and v2 projects still open.
