3ステップで完了

エクスポートする前に重要な設定を確認してください。処理場所は常に開示されます。

01

ビデオをインポートして背景を選択する

MP4、WebM、または MOV をインポートし、フレームを引き伸ばしたりトリミングしたりせずに、透明、ソリッド、ローカル画像、またはぼかしたソース背景を選択します。

02

モデルを選択してプレビューする

7.2 MB RVM 互換、51.3 MB RVM 品質、または RVM ResNet50 によって最初のフレームで校正された MatAnyone2 非商用テスト層を選択します。

03

ローカルで処理してエクスポートする

WebCodecs はフレームごとの結果をエンコードし、ソース オーディオを再多重化します。不透明な背景のデフォルトは MP4 です。透明性は WebM を使用します。

「ラボグレード」および「現在のテストで最高」とは何を意味しますか?

ImgIng は、動画背景切り抜きを品質第一のラボグレードのベータ版として扱います。評価は静止したアウトライン以上のものを対象としており、髪の毛、交差する手足、速い動き、低コントラストのエッジ、被写体のない開口部、シーンカット後の時間的安定性を検査します。現在の代表的な内部サンプルでは、​​MatAnyone2 Ultimate tier が、ImgIng がテストした同等のブラウザ側ソリューションの中で全体的に最良の切り抜き結果を生成しました。これは範囲を限定した暫定的な結果であり、すべての製品、デバイス、または考えられるクリップの絶対的なランキングではなく、公開ベンチマーク セットが拡大するにつれて更新されます。

すべてのフレームで静止画の切り抜きモデルを実行してみてはいかがでしょうか?

独立したフレームにより、髪や半透明のエッジがちらつく場合があります。 ImgIng の RVM パスは、反復的な一時的な状態を伝送し、検出されたシーン カットでそれをリセットします。実験層では、最初に RVM ResNet50 を使用して最初のフレームのヘアと完全なシルエットをキャリブレーションし、次にそのシードを MatAnyone2 メモリ伝播に渡して、初期の省略、ジッター、前のショットの残留物を削減します。

3 つのモデルのうちどれを選択すればよいですか?

RVM MobileNetV3 FP16 は約 7.2 MB で、クイック プレビュー、一般的なデバイス、および長いビデオに適しています。 RVM ResNet50 FP16 は約 51.3 MB で、速度と引き換えに安定した詳細を実現します。 MatAnyone2 は、約 294 MB の横向き、正方形、または縦向きのプロファイルを自動的に選択し、最初のフレームのキャリブレーションに 51.3 MB の RVM ResNet50 モデル (合計約 345 MB) を再利用します。非商業的なテストのみを目的としています。すべてのモデルは最初に ModelScope CDN を使用し、ImgIng 上の同じ固定バージョンにフォールバックし、検証後にのみブラウザー キャッシュに入ります。

異常なビデオ比率が引き伸ばされることはありますか?

いいえ。ワークスペースでは、元のフレーム比とエクスポート寸法が保持されます。推論のためにソースを強制的に正方形にしたり、表示されているフレームを切り取ったりすることはありません。 MatAnyone2 は、使用可能な分析領域が最大である内部の横長、正方形、または縦長の入力のみを選択します。最初のフレームのキャリブレーションでは、最終出力寸法を変更せずに、1920 ピクセルの長さのエッジで超高解像度入力を比例的に制限してメモリを制御します。背景画像は個別にカバーまたは包含をサポートします。

初めに主語が存在しない場合はどうなるでしょうか?

実験段階では、開始フレームに主題がないという理由だけで完全なエクスポートが中止されることがなくなりました。パイプラインが検索を続けている間、これらのフレームは選択された背景を出力します。一時記憶は人が検出されると始まります。シーン カットは以前のメモリをクリアし、キャリブレーションを再度実行します。

通常の Chrome ブラウザでも実行できますか?

現在のデスクトップの Chrome と Edge が主なターゲットです。ページには HTTPS または localhost、WebCodecs、WebAssembly が必要です。 RVM は安定した WASM 推論パスを使用します。 MatAnyone2 は WebGPU を優先し、WASM にフォールバックできます。古いデバイス、電話、長い 4K ビデオは実用的ではない可能性があるため、ワークスペースは機能を検出し、ダウンロードと処理 ETA を報告します。

ベータ版の制限: ビデオ全体を処理する前に、現在のフレームをプレビューします。複雑なオクルージョン、高速モーション、半透明のオブジェクト、シーン カットでは、依然としてエッジ エラーが発生する可能性があります。 「任意のアスペクト比」とは、引き伸ばしやトリミングを行わないことを意味します。あらゆる極端な構図に対して同一の切り抜き精度を保証するものではありません。透明なビデオは WebM VP9 アルファとしてエクスポートされます。 MP4 は、ソリッド、イメージ、またはぼかした不透明な背景用です。

よくある質問

これらの目に見える答えは、現在の製品の動作と構造化データと一致します。

動画はサーバーにアップロードされますか?

いいえ。完全な動画背景切り抜き パイプラインはブラウザー内に残ります。ネットワークは、最初の使用時にランタイムと選択したモデルをダウンロードするためにのみ使用されます。

「現在のテストで最高」というのは絶対的な業界ランキングなのでしょうか？

いいえ。これは、評価された同等のブラウザ側ソリューションの中で、現在の代表的な内部サンプルに関して、MatAnyone2 究極層が総合的に最良の結果をもたらしたことを意味します。難しい映像もプレビューする必要があり、ベンチマークの範囲は拡大し続けます。

MatAnyone2 のダウンロードが非常に大きいのはなぜですか?

現在のアスペクト クラスの約 294 MB の時間プロファイルをロードし、最初のフレームのキャリブレーションに約 51.3 MB の RVM ResNet50 モデル (合計約 345 MB) を再利用します。時間がかかりますが、非商業的なテストのみに使用されます。

元の音声は保持されますか?

デフォルトでははい。互換性のあるオーディオがコピーされます。それ以外の場合は、WebM の場合は Opus、MP4 の場合は AAC にエンコードされ、再多重化されます。
