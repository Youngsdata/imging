クリーンページ HTML · ベータ版

PDF ページを 1 つのきれいな固定レイアウト HTML に変換します

PDF はページ説明形式であり、通常の Web コンテンツをリフローするものではありません。 ImgIng は PDF 座標でページを再構成し、タイプ 3 グリフ、インラインおよびマスクされたイメージ、ICC およびインデックス付きカラー、タイリング パターン、軸方向および放射状のグラデーション、および一般的なソフト マスクをサポートし、ページごとに残りのレビュー ケースを識別します。

3ステップで完了

エクスポートする前に重要な設定を確認してください。処理場所は常に開示されます。

01

PDFを選択してください

ファイルはこのブラウザでは読み取り専用です。所有者は、暗号化された PDF または権限で保護された PDF のロックを最初に解除する必要があります。

02

ページをローカルで再構築する

ToUnicode、ページ回転、クロップボックス、リンク、使用可能なフォントを読み取りながら、PDF 座標でテキスト、パス、画像を再作成します。

03

プレビュー、検査、保存

固定レイアウトの結果と複雑な機能のレポートを確認し、システムの保存ダイアログを使用して 1 つの HTML ファイルをエクスポートします。

すべての PDF がピクセル差ゼロの通常の HTML になることを約束してはどうでしょうか?

PDF には最終的な描画手順が保存されます。通常の HTML は、ブラウザ、フォント、ビューポートの違いでリフローされます。メッシュ シェーディング、異常なブレンディング、複雑なクリッピング、フォーム、3D、およびマルチメディアにも、完全に 1 対 1 の HTML に相当するものはありません。したがって、ImgIng は固定レイアウトの SVG を使用します。ページの寸法、テキスト マトリックス、ベクトル パス、画像の位置は PDF 座標に従いますが、テキストは選択可能なままです。同等でない機能は、完全な変換として黙って表示されるのではなく、ワークスペースのページごとのレポートに記録されます。

複雑なグリフ、色、画像、グラデーションはどのように再現されるのでしょうか?

ImgIng は Type 3 CharProcs を読み取り、各グリフを再利用可能な SVG ベクトル シンボルとしてキャッシュし、非表示の選択レイヤーを追加します。 ICCBased フォールバック、インデックス付きパレット、インライン イメージ、1 ビット ImageMask ステンシル、JPEG ソフト マスク、および一般的なグラフィックス状態ソフト マスクを処理します。 PatternType 1 タイリング パターン、PatternType 2 軸方向シェーディング、および ShadingType 3 放射状シェーディングは、アクティブなグラフィックス マトリックスを 2 回乗算することなく、インライン SVG リソースになります。

すべてを 1 つのきれいな HTML ファイルに収めるにはどうすればよいでしょうか?

各ページの固定レイアウトの SVG、画像、許可されたフォント、および必要な CSS がインライン化されます。エクスポートには実行可能なビューア ランタイムはなく、元の PDF のコピーは含まれず、ズーム、レポート、印刷、または元のファイルのツールバーも追加されません。ファイルを開くと、すぐにページが表示されます。品質レポートは、保存する前にソース比較のために変換ワークスペースに残ります。

フォントのアクセス許可が個別にチェックされるのはなぜですか?

PDF に埋め込まれたフォントには、別のドキュメントにコピーするためのライセンスが自動的に付与されません。 ImgIng は、OpenType OS/2 fsType フィールドを読み取ります。インストール可能、編集可能、またはプレビュー/印刷の埋め込みが許可されているブラウザーで使用可能なフォントは、これらの制限内でインライン化できます。制限付きライセンスおよびビットマップのみのフォントはコピーされません。このリリースではフォントのサブセットを作成せず、埋め込みが禁止されている場合に安全なフォールバックを使用し、置換について文書化します。

セキュリティ境界線とは何ですか?

コンバーターは PDF JavaScript を実行したり、PDF アクションを Web スクリプトに変換したりすることはなく、プロトコル チェック後に http、https、または mailto 注釈のみを保持します。出力検証では外部スクリプト、スタイルシート、画像、またはフォントの読み込みが拒否され、生成されたドキュメントにはコンテンツ セキュリティ ポリシーが含まれます。

ベータ版の制限: このリリースは、自動レスポンシブ記事変換やドラッグ アンド ドロップ Web エディターではなく、固定レイアウトの読み取り、アーカイブ、共有、視覚的再現に焦点を当てています。孤立グループまたはノックアウト グループ、特別な伝達関数またはマット プリマルチプリケーションを備えたマスク、CMYK スクリーン カラー、クロスブラウザ JPEG 2000、メッシュ シェーディング、テキスト クリッピング、複雑なフォームおよびマルチメディアは、依然としてレビューが必要な場合があります。ワークスペースは影響を受けるページを特定します。

よくある質問

これらの目に見える答えは、現在の製品の動作と構造化データと一致します。

PDFと結果はアップロードされていますか?

いいえ。解析、ページの再構築、フォント チェック、プレビュー、HTML パッケージ化はすべてローカルで行われます。

エクスポートされた HTML はオフラインで開くことができますか?

はい。 CSS、ページ SVG、画像、および許可されたフォントはインライン化されます。結果には ImgIng サーバーは必要なく、ビューア ツールバーも含まれません。

フォントが正確に埋め込まれないのはなぜですか?

そのライセンスでは、コピーが禁止されている場合や、特定の埋め込みモードのみが許可されている場合があります。 ImgIng は OpenType fsType を尊重し、制限付きライセンスをバイパスせず、置換を報告します。

画像の探索

各タスク ページには、キーワードを交換した重複ではなく、実際の設定、制限、形式に関するアドバイスが文書化されています。
