PDF 转 HTML：固定版式正文装进一个纯净 HTML

PDF 是页面描述格式，不等同于普通网页。图映按 PDF 坐标重建页面，支持 Type 3 矢量字形、平铺图案、轴向与径向渐变、内联与蒙版图片及常见软蒙版，同时按页标记仍需验收的专有特性；成品无外部资源、查看器运行时或原 PDF。

选择 PDF

文件只在当前浏览器读取；加密或权限保护的 PDF 需要先由文件所有者解除保护。

02

本地重建页面

按 PDF 坐标重建文字、路径和图片，读取 ToUnicode、页面旋转、裁切框、链接与可用字体。

03

预览、看报告并保存

先检查固定版式结果和复杂特性清单，再用系统保存窗口导出一个可独立打开的 HTML。

为什么不承诺所有 PDF 都能变成“普通 HTML 且一像素不差”？

PDF 保存的是最终页面绘制指令，而普通 HTML 会随字体、浏览器和窗口宽度重新排版。网格着色、特殊混合、复杂裁剪、表单、3D 与多媒体也没有完全一一对应的 HTML 元素。图映因此采用固定版式 SVG：页面尺寸、文字矩阵、矢量路径与图片位置按 PDF 坐标还原，文字仍可选择；检测到不等价特性时不会假装成功，而是写入转换工作台的逐页质量报告。

复杂字形、颜色、图片和渐变怎样还原？

图映读取 Type 3 字体 CharProcs 的原始绘制指令，把字形缓存为可复用 SVG 矢量符号并叠加透明选择层；支持 ICCBased 回退、Indexed 调色板、内联图片、一位 ImageMask、JPEG 软蒙版与常见图形状态软蒙版。PatternType 1 平铺图案、PatternType 2 轴向着色和 ShadingType 3 径向着色会转换成内联 SVG 资源，且不会重复乘当前绘图矩阵。

怎样做到只有一个纯净 HTML？

每一页的固定版式 SVG、图片、获准字体和必要样式全部直接内联。导出成品没有可执行的查看器运行时，不携带原 PDF，也不加入缩放、报告、打印或取回原文件等工具栏；双击文件后直接看到标准页面正文。质量报告只留在转换工作台，保存前可以对照源 PDF 验收。

字体为什么需要单独检查许可？

PDF 内嵌字体并不自动意味着可以复制进另一个文档。图映读取 OpenType OS/2 表的 fsType：允许安装、编辑或预览/打印嵌入的浏览器字体可按许可内联；Restricted License 或只允许位图嵌入的字体不会被复制。当前版本不做字体子集化，禁止嵌入时使用安全替代并在报告中说明。

安全边界是什么？

转换器不执行 PDF JavaScript，不把 PDF 动作变成网页脚本，只保留经过协议白名单检查的 http、https 与 mailto 链接。输出会校验没有外部 script、stylesheet、图片或字体加载地址，并使用内容安全策略限制网络能力。

Beta 边界：当前重点是固定版式阅读、归档、分享和视觉还原，不是把 PDF 自动改写成响应式文章或可任意拖拽的网页编辑器。隔离 / 挖空透明组、带特殊传递函数或 Matte 预乘底色的软蒙版、CMYK 屏幕色彩、JPEG 2000 跨浏览器显示、网格着色、文字轮廓裁剪、复杂表单与多媒体仍可能需要验收；工作台会标明具体页码。

常见问题

下列答案与当前产品逻辑和页面结构化数据保持一致。

PDF 和转换后的内容会上传吗？

不会。解析、页面重建、字体检查、预览和 HTML 封装都在浏览器本地完成。

导出的 HTML 离线能打开吗？

可以。页面样式、SVG、图片和获准字体都内联，成品不需要图映服务器，也没有查看器菜单。

为什么有的字体没有原样嵌入？

因为字体授权可能禁止复制或只允许特定嵌入方式。图映尊重 OpenType fsType，不绕过 Restricted License，并把替代情况写进报告。
