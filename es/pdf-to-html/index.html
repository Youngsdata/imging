¿Por qué no prometer que cada PDF se convertirá en HTML normal y sin diferencias de píxeles?

El PDF almacena las instrucciones de dibujo finales. El HTML ordinario se redistribuye con diferencias en el navegador, la fuente y la ventana gráfica. El sombreado de malla, las mezclas inusuales, el recorte complejo, los formularios, el 3D y los multimedia tampoco tienen un equivalente HTML uno a uno completo. Por lo tanto, ImgIng utiliza SVG de diseño fijo: las dimensiones de la página, las matrices de texto, las rutas vectoriales y las posiciones de las imágenes siguen las coordenadas PDF mientras el texto sigue siendo seleccionable. Cualquier característica no equivalente se registra en el informe por página del espacio de trabajo en lugar de presentarse silenciosamente como una conversión perfecta.

¿Cómo se reproducen los glifos, colores, imágenes y degradados complejos?

ImgIng lee CharProcs de tipo 3, almacena en caché cada glifo como un símbolo vectorial SVG reutilizable y agrega una capa de selección invisible. Maneja respaldos basados ​​en ICC, paletas indexadas, imágenes en línea, plantillas ImageMask de un bit, máscaras suaves JPEG y máscaras suaves de estado de gráficos comunes. Los patrones de mosaico PatternType 1, los sombreados axiales PatternType 2 y los sombreados radiales ShadingType 3 se convierten en recursos SVG en línea sin multiplicar dos veces la matriz de gráficos activa.

¿Cómo puede caber todo en un archivo HTML limpio?

El SVG de diseño fijo de cada página, las imágenes, las fuentes permitidas y el CSS necesario están integrados. La exportación no tiene un tiempo de ejecución de visor ejecutable, no incluye ninguna copia del PDF original y no agrega zoom, informe, impresión ni barra de herramientas de archivo original. Abra el archivo y las páginas aparecerán inmediatamente. El informe de calidad permanece en el espacio de trabajo de conversión para comparar el origen antes de guardarlo.

¿Por qué los permisos de fuentes se verifican por separado?

Una fuente incrustada en un PDF no tiene licencia automática para copiarla en otro documento. ImgIng lee el campo fsType de OpenType OS/2. Las fuentes utilizables por el navegador permitidas para instalación, edición o incrustación de vista previa/impresión pueden incluirse dentro de esos límites; Las fuentes de licencia restringida y de mapa de bits únicamente no se copian. Esta versión no crea subconjuntos de fuentes, utiliza un recurso seguro cuando está prohibida la incrustación y documenta la sustitución.

¿Cuál es el límite de seguridad?

El conversor nunca ejecuta PDF JavaScript, nunca convierte acciones de PDF en scripts web y conserva solo anotaciones http, https o mailto después de las comprobaciones del protocolo. La validación de salida rechaza cargas de secuencias de comandos, hojas de estilo, imágenes o fuentes externas, y el documento generado incluye una Política de seguridad de contenido.

Límites beta: Esta versión se centra en la lectura, el archivado, el intercambio y la reproducción visual de diseño fijo, no en la conversión automática de artículos responsivos ni en un editor web de arrastrar y soltar. Los grupos aislados o knockout, máscaras con funciones de transferencia especiales o premultiplicación mate, color de pantalla CMYK, JPEG 2000 para varios navegadores, sombreado de malla, recorte de texto, formularios complejos y multimedia aún pueden requerir revisión; el espacio de trabajo identifica las páginas afectadas.

Preguntas frecuentes

Estas respuestas visibles coinciden con el comportamiento actual del producto y los datos estructurados.

¿Se cargan el PDF y el resultado?

No. El análisis, la reconstrucción de páginas, las comprobaciones de fuentes, la vista previa y el empaquetado HTML se realizan localmente.

¿El HTML exportado se abrirá sin conexión?

Sí. CSS, SVG de página, imágenes y fuentes permitidas están incorporadas; el resultado no necesita ningún servidor ImgIng y no contiene ninguna barra de herramientas del visor.

¿Por qué es posible que una fuente no esté incrustada exactamente?

Su licencia puede prohibir la copia o permitir sólo un modo de incrustación específico. ImgIng respeta OpenType fsType, no omite la licencia restringida e informa la sustitución.
