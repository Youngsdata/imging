¿Qué significa 45,8 dB?

Es un resultado de referencia PNG-8 de 256 colores existente que se utiliza para detectar regresiones de algoritmos. No es un promedio, una garantía universal ni una prueba suficiente de que una herramienta siempre gana. Las capturas de pantalla, fotografías, ilustraciones planas y sombras alfa necesitan grupos de prueba separados.

La elección del formato importa más que una “calidad 80” universal

Prefiere WebP, JPG o AVIF para fotos; PNG-8 para gráficos alfa de colores limitados; GIF para un alcance máximo de animación; WebP para animación web moderna; y APNG para animaciones alfa breves y en color verdadero.

Preguntas frecuentes

Estas respuestas visibles coinciden con el comportamiento actual del producto y los datos estructurados.

¿Es siempre mejor un PSNR más alto?

No. PSNR es útil para la regresión de píxeles, mientras que la textura, los contornos, el texto y los bordes transparentes percibidos aún requieren inspección visual.

¿45,8 dB es un promedio en todas las imágenes?

No. Es una muestra de referencia actual de 256 colores, no un resultado universal.

¿Las pruebas de códec deberían utilizar el mismo tamaño de archivo?

Tanto las comparaciones de igual tamaño como las de igual calidad son útiles, pero sus conclusiones no deben confundirse.
