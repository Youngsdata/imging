¿Por qué algunos GIF son difíciles de reducir?

GIF está limitado a 256 colores, pero las dimensiones, el número de fotogramas, las regiones cambiadas y el tramado afectan el tamaño. Un GIF muy optimizado puede necesitar un cambio de tamaño, una reducción de fotogramas o un formato diferente para volverse significativamente más pequeño.

¿GIF, WebP animado o APNG?

GIF gana en reproducción universal. WebP animado suele ser el mejor equilibrio entre la web moderna. APNG conserva todo color y alfa para pegatinas de alta fidelidad. ImgIng permite que los mismos fotogramas generen diferentes resultados en lugar de pretender que un formato se adapta a cada uso.

Preguntas frecuentes

Estas respuestas visibles coinciden con el comportamiento actual del producto y los datos estructurados.

¿La compresión GIF cambiará la velocidad de reproducción?

No por defecto. ImgIng lee y conserva los retrasos de fotogramas originales a menos que cambie explícitamente la velocidad o el tiempo de fotograma.

¿Puedo crear un GIF a partir de varias imágenes?

Sí. Importe varias imágenes, arrástrelas para reordenarlas, establezca la duración por cuadro, el bucle y la dirección de reproducción.

¿Las animaciones se procesan localmente?

En los navegadores compatibles, la decodificación y codificación de GIF, APNG y WebP animada se realizan localmente. La interfaz informa claramente de capacidades faltantes.
