Why can PNG-8 be much smaller?

True-colour PNG can represent millions of colours, while many icons and interface screenshots need far fewer. PNG-8 builds a compact palette and stores a palette index per pixel, cutting redundant colour data.

Why is transparent PNG harder to compress?

Anti-aliased edges and shadows use many alpha levels, not just transparent or opaque. ImgIng preserves multi-level alpha instead of forcing soft edges into a jagged binary mask.

The 45.8 dB figure is a regression reference from one existing 256-colour sample. It is not a promise for every image; visual detail, alpha edges and file size should be evaluated together.

Frequently asked questions

These visible answers match the current product behaviour and structured data.

Does PNG-8 destroy transparency?

No. ImgIng supports multiple alpha levels in indexed PNG instead of reducing transparency to two states.

Should photographs use PNG-8?

Usually not. WebP, JPG or AVIF is generally better for continuous-tone photos; PNG-8 suits graphics with a limited palette.

Should dithering always be enabled?

No. Dithering may improve low-colour gradients, but it can also add texture and bytes. ImgIng leaves it off by default.
