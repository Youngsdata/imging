The 51.3 MB model prioritises quality; use the 7.2 MB compatible model for typical computers or longer videos. Download speed and ETA are shown.

03

Process locally and export

Temporal matting runs frame by frame, WebCodecs encodes the result, and source audio is remuxed into WebM or MP4.

Why not run a still-image cutout model on every frame?

Independent frames can make hair and translucent edges flicker. Robust Video Matting carries recurrent temporal state between frames and ImgIng resets that state on detected scene cuts, reducing edge jitter and previous-shot residue.

Can a normal Chrome browser run it?

Current desktop Chrome and Edge are the primary targets. The page needs HTTPS or localhost, WebCodecs and WebAssembly. WebGPU uses the GPU when available, while WASM provides a slower fallback. Older devices, phones and long 4K video may be impractical, so the workspace detects capabilities first and reports processing progress and ETA.

Why are there two models?

RVM ResNet50 FP16 is the quality-first default for hair and complex edges. RVM MobileNetV3 FP16 has a smaller download for typical devices, longer video and faster previews. Exact byte length and SHA-256 are verified before a model enters browser cache.

Transparent video exports as WebM VP9 alpha. MP4 has no alpha channel and is intended for solid, image or blurred opaque backgrounds. Chrome with File System Access writes output progressively to disk to reduce memory pressure.

Frequently asked questions

These visible answers match the current product behaviour and structured data.

Does the video upload to a server?

No. The complete video editing pipeline stays in the browser; the network is used only to download the runtime and selected model on first use.

Why can quality mode take a long time?

It uses the larger ResNet50 temporal model and must decode, infer, composite and encode every frame. Time depends on dimensions, duration, frame rate and GPU.

Is the original audio retained?

Yes by default. Compatible audio is copied; otherwise it is encoded to Opus for WebM or AAC for MP4 and remuxed.
