Fast colour removal or AI?

Connected-edge removal is ideal for product art and graphics surrounded by a consistent colour. It removes only similar pixels connected to the canvas edge, protecting matching details inside the subject. People, hair and complex scenes are better suited to AI.

Why does the default preserve the model edge?

The default path uses the model alpha channel pixel for pixel. Edge contraction, feathering and colour decontamination run only when you enable them, so compact preview, professional editor and full-size export can share the same mask.

How can I compose the cutout without another editor?

Professional refinement can keep transparency or use a solid colour or local image as the background. Move and scale the subject and background independently, then choose the source canvas, 1:1, 4:5, 16:9 or a custom size. Dragging updates CSS transforms only; full-resolution pixel compositing waits until export to keep large-image interaction responsive.

Model and background files stay in local browser memory. Downloading a model does not upload the source image.

Frequently asked questions

These visible answers match the current product behaviour and structured data.

Which AI model is best for a modest computer?

ISNet INT8 Fast AI is recommended by default. Its smaller download and faster inference suit CPU-only and lower-spec devices.

Does the result preserve partial transparency?

Yes. The mask retains the complete 0–255 alpha range, and alpha-capable outputs such as WebP and PNG preserve soft edges.

Why might the model download again?

The browser normally reuses Cache Storage. Clearing site data, using a private window or browser cache eviction can require another download.
