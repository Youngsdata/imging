PDF 페이지를 하나의 깔끔한 고정 레이아웃 HTML로 변환

PDF는 일반적인 리플로우 웹 콘텐츠가 아닌 페이지 설명 형식입니다. ImgIng는 PDF 좌표로 페이지를 재구성하고 Type 3 글리프, 인라인 및 마스크된 이미지, ICC 및 인덱스 색상, 타일링 패턴, 축 및 방사형 그래디언트 및 일반적인 소프트 마스크를 지원한 다음 페이지별로 나머지 검토 사례를 식별합니다.

3단계로 완료

내보내기 전에 중요한 설정을 확인하세요. 처리 위치는 항상 공개됩니다.

01

PDF를 선택하세요

이 브라우저에서는 파일을 읽을 수만 있습니다. 소유자는 먼저 암호화되었거나 권한으로 보호된 PDF의 잠금을 해제해야 합니다.

02

로컬에서 페이지 다시 작성

ToUnicode, 페이지 회전, 자르기 상자, 링크 및 사용 가능한 글꼴을 읽는 동안 PDF 좌표에서 텍스트, 경로 및 이미지를 다시 만듭니다.

03

미리보기, 검사 및 저장

고정 레이아웃 결과와 복합 기능 보고서를 검토한 다음 시스템 저장 대화 상자를 사용하여 하나의 HTML 파일을 내보냅니다.

모든 PDF가 픽셀 차이가 없는 일반 HTML이 된다고 약속하는 것은 어떨까요?

PDF는 최종 도면 지침을 저장합니다. 일반 HTML은 브라우저, 글꼴 및 뷰포트 차이로 리플로우됩니다. 메쉬 셰이딩, 특이한 블렌딩, 복잡한 클리핑, 양식, 3D 및 멀티미디어에도 완전한 일대일 HTML이 없습니다. 따라서 ImgIng은 고정 레이아웃 SVG를 사용합니다. 페이지 크기, 텍스트 행렬, 벡터 경로 및 이미지 위치는 PDF 좌표를 따르며 텍스트는 계속 선택할 수 있습니다. 동일하지 않은 기능은 완벽한 변환으로 자동으로 표시되는 대신 작업공간 페이지별 보고서에 기록됩니다.

복잡한 글리프, 색상, 이미지 및 그라데이션은 어떻게 재현됩니까?

ImgIng는 Type 3 CharProcs를 읽고 각 글리프를 재사용 가능한 SVG 벡터 기호로 캐시하고 보이지 않는 선택 레이어를 추가합니다. ICCBased 폴백, 인덱스 팔레트, 인라인 이미지, 1비트 ImageMask 스텐실, JPEG 소프트 마스크 및 일반적인 그래픽 상태 소프트 마스크를 처리합니다. PatternType 1 타일링 패턴, PatternType 2 축 음영 및 ShadingType 3 방사형 음영은 활성 그래픽 매트릭스를 두 번 곱하지 않고도 인라인 SVG 리소스가 됩니다.

어떻게 모든 것이 하나의 깨끗한 HTML 파일에 들어갈 수 있습니까?

각 페이지의 고정 레이아웃 SVG, 이미지, 허용되는 글꼴 및 필수 CSS가 인라인됩니다. 내보내기에는 실행 가능한 뷰어 런타임이 없으며 원본 PDF 사본이 없으며 확대/축소, 보고서, 인쇄 또는 원본 파일 도구 모음이 추가되지 않습니다. 파일을 열면 페이지가 즉시 나타납니다. 품질 보고서는 저장하기 전에 소스 비교를 위해 변환 작업 공간에 남아 있습니다.

글꼴 권한을 별도로 확인하는 이유는 무엇입니까?

PDF에 포함된 글꼴은 다른 문서에 복사할 수 있는 라이선스가 자동으로 부여되지 않습니다. ImgIng는 OpenType OS/2 fsType 필드를 읽습니다. 설치, 편집 또는 미리보기/인쇄 포함이 허용된 브라우저에서 사용 가능한 글꼴은 해당 제한 내에서 인라인될 수 있습니다. 제한된 라이센스 및 비트맵 전용 글꼴은 복사되지 않습니다. 이 릴리스에서는 글꼴을 하위 집합으로 지정하지 않고 포함이 금지된 경우 안전한 대체 기능을 사용하며 대체 내용을 문서화합니다.

보안 경계는 무엇입니까?

변환기는 PDF JavaScript를 실행하지 않으며 PDF 작업을 웹 스크립트로 변환하지 않으며 프로토콜 확인 후 http, https 또는 mailto 주석만 유지합니다. 출력 유효성 검사는 외부 스크립트, 스타일시트, 이미지 또는 글꼴 로드를 거부하고 생성된 문서에는 콘텐츠 보안 정책이 포함됩니다.

베타 한도: 이 릴리스는 자동 반응형 기사 변환이나 드래그 앤 드롭 웹 편집기가 아닌 고정 레이아웃 읽기, 보관, 공유 및 시각적 재생산에 중점을 둡니다. 격리된 그룹 또는 녹아웃 그룹, 특수 전송 기능이 있는 마스크 또는 매트 사전 곱셈, CMYK 화면 색상, 크로스 브라우저 JPEG 2000, 메시 셰이딩, 텍스트 클리핑, 복잡한 양식 및 멀티미디어는 여전히 검토가 필요할 수 있습니다. 작업공간은 영향을 받은 페이지를 식별합니다.

자주 묻는 질문

이러한 눈에 보이는 답변은 현재 제품 동작 및 구조화된 데이터와 일치합니다.

PDF와 결과가 업로드되나요?

아니요. 구문 분석, 페이지 재구성, 글꼴 확인, 미리 보기 및 HTML 패키징은 모두 로컬에서 발생합니다.

내보낸 HTML이 오프라인으로 열리나요?

그렇습니다. CSS, 페이지 SVG, 이미지 및 허용되는 글꼴이 인라인됩니다. 결과에는 ImgIng 서버가 필요하지 않으며 뷰어 도구 모음도 포함되어 있지 않습니다.

글꼴이 정확히 포함되지 않는 이유는 무엇입니까?

해당 라이센스는 복사를 금지하거나 특정 삽입 모드만 허용할 수 있습니다. ImgIng은 OpenType fsType을 존중하고 제한된 라이센스를 우회하지 않으며 대체를 보고합니다.
